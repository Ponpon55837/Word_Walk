# WP-1 驗收紀錄

2026-11-11，在 Windows 的 Agent Pets 1.14.0 隔離設定檔驗收獨立插件「單字散步」。套件識別碼為 `word-walk`，初始 manifest 版本為 `0.1.0`，使用 Host API 1。

## 交付範圍

採用提案的首發預設，內容為日文 N5 與英文釋義，介面可切換繁中及英文。WP-1 提供手動開啟、本次記憶體練習、提示、翻面、自評、有限次重看、完成統計與來源頁。Worker 持有當前卡片，面板重建後先取回快照。

## 安全設計與限制

題庫網址固定到單一 Git commit。下載成功後先比對長度與雜湊，再解析 JSON。遠端詞條只以文字顯示，例句外連由正整數的 Tatoeba ID 組成。面板只送操作意圖；每次狀態變更後 Worker 更新 token，使延遲的舊評分無法套用到下一張。清單中的來源連結須由使用者操作開啟。

插件沒有第三方執行依賴。宿主的 HTTPS 代理、CSP、外連同意與 Worker 隔離仍是信任邊界。套件尚未簽章。此次驗收涵蓋 Windows 深色面板、雙語文案及鍵盤翻面。macOS、其他 DPI、淺色佈景與螢幕閱讀器仍待實機驗證。資料結構檢查涵蓋每筆內容，逐詞語義與例句適齡性尚未完成人工審校。

## 重跑 Electron 驗收

先建置本插件套件與 Agent Pets。從宿主倉庫執行以下指令，使用空閒的本機埠。啟動器會印出此次專屬的暫存根目錄。

```powershell
node scripts/e2e-isolated-electron.mjs --offscreen --inspect-port 29751 --debug-port 29752 --hook-port-base 29753
```

在單字散步倉庫另開終端，將最後一個參數換成啟動器印出的完整路徑。

```powershell
node tests/electron.mjs 29751 29752 "<隔離暫存根目錄>"
```

測試會先核對隔離根目錄與除錯埠，再透過宿主安裝及啟用封裝檔，產生 `build/word-walk-card.png` 並驗證本輪流程。成功後卸載測試插件並退出該實例。

下一階段 WP-2 涉及持久化資料格式、每日選卡、間隔複習與備份還原。版本決策留到該階段驗收。
